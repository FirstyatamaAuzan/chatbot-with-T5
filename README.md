# Chatbot with T5

A simple AI chatbot project built with the **T5 (Text-to-Text Transfer Transformer)** model.

This project explores the use of Transformer-based Natural Language Processing (NLP) to generate conversational responses from user input.

## Features

- 🤖 AI-powered conversational chatbot
- 🧠 Uses the T5 Transformer model
- 💬 Text-based question and answer interaction
- 🔤 Natural Language Processing (NLP)
- 🐍 Python-based implementation

## Tech Stack

- Python
- T5 / Hugging Face Transformers
- PyTorch
- NLP

## How It Works

```text
User Input
    │
    ▼
Text Preprocessing
    │
    ▼
T5 Transformer Model
    │
    ▼
Generated Response
    │
    ▼
Chatbot Output
```

## Installation

Clone the repository:

```bash
git clone https://github.com/FirstyatamaAuzan/chatbot-with-T5.git
cd chatbot-with-T5
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the project according to the provided Python script or notebook.

## Project Purpose

This project was created to learn and implement **Transformer-based NLP**, particularly the T5 architecture, in a conversational chatbot application.

It can also serve as a starting point for experimenting with text generation, question answering, and conversational AI.
